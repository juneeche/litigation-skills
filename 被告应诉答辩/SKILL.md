# 被告应诉答辩

客户收到起诉状、传票、证据、保全裁定或法院通知后，应立即使用本 skill。

目标是在关键期限内保护程序权利，识别程序机会，并尽快搭建抗辩体系。

## 输入材料

- 起诉状、证据、传票、应诉通知、举证通知、法院短信或平台消息
- 送达日期和送达方式
- 客户掌握的事实和文件
- 是否存在保全裁定或账户冻结
- 合同、往来函件、付款记录、履行记录

## 工作流

1. 登记程序期限
   - 答辩期限
   - 管辖异议期限
   - 举证期限
   - 开庭时间
   - 保全复议期限
   - 如处于特殊程序，还需登记上诉、复议或异议期限

2. 拆解原告诉讼结构
   - 诉讼请求
   - 案由
   - 原告主张的事实
   - 支撑每项主张的证据
   - 原告诉请和证据中的漏洞、矛盾

3. 检查程序抗辩
   - 管辖异议
   - 仲裁协议
   - 被告不适格或遗漏必要当事人
   - 重复起诉
   - 诉讼时效
   - 原告主体资格问题
   - 送达或程序瑕疵

4. 搭建实体抗辩
   - 否认合同或法律关系
   - 合同效力问题
   - 已履行
   - 原告先违约
   - 抵销、扣减、质量问题、不可抗力、情势变更、减损义务、因果关系、损失计算
   - 利息、违约金、律师费、费用承担的抗辩

5. 决定应对动作
   - 提管辖异议
   - 提交答辩状
   - 提起反诉
   - 申请追加第三人
   - 申请鉴定、审计、法院调查或证据保全
   - 启动和解谈判

6. 准备应诉文件
   - 答辩状
   - 管辖异议申请书
   - 反诉状
   - 证据目录
   - 保全复议或异议材料

## 输出成果

- 应诉期限表
- 原告诉请拆解表
- 程序抗辩 memo
- 实体抗辩矩阵
- 答辩状
- 管辖异议申请书
- 反诉评估及草稿
- 证据回应清单
- 和解风险说明

## 风险检查

必须提示：

- 先进行实体答辩可能影响管辖异议策略
- 反诉会影响费用、审理范围和案件节奏
- 客户承认事实可能削弱抗辩
- 保全冻结可能需要紧急复议或置换担保
- 客户掌握的关键证据需要立即固定
- 对关键事实沉默可能影响后续抗辩空间

## 交接节点

使用 `证据管理` 整理被告证据。

进入开庭或庭前会议阶段后，交接至 `庭前与庭审准备`。
