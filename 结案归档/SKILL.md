# 结案归档

凡是用户要求结案、归档、填写卷宗目录、填写结案报告、按归档范例合并 PDF 时，使用本 skill。

目标是：不改变模板格式，只按归档流程把材料整理成可提交的归档文件。

## 必须使用的本地模板

优先使用工作区中的：

- `文书模板/归档/卷 宗 目 录.doc`
- `文书模板/归档/结案报告.docx`
- `文书模板/归档/结案流程及要求.pdf`
- `文书模板/归档/归档范例.pdf`

如果案件自己的 `归档-整理` 文件夹中已有用户填写过的 `卷 宗 目 录.doc` 或 `结案报告.docx`，以用户填写版本为准，不要用自动生成版本覆盖用户格式。

## 核心原则

- 不重设计模板。
- 不新建表格代替模板表格。
- 不改变字体、字号、行距、边框、表格线、段落结构。
- 只在模板预留位置填写内容。
- 用户手工填写或纠正过的内容优先级最高。
- 原始材料不删除、不移动；生成成果放入 `归档-整理`。

## 卷宗目录填写规则

使用 `卷 宗 目 录.doc`。

如果工具不能直接编辑 `.doc`，可以转换为工作副本 `.docx`，但必须尽量保留模板位置和样式。该模板可能不是标准 Word 表格，而是由固定位置段落/框线组成；遇到这种情况，不要新建表格，按原位置段落填字。

只填写左侧两栏：

- `文书名称`
- `页次`

右侧多余两栏保持空白，除非用户明确要求填写右侧。

不要在卷宗目录中额外添加说明、提示、缺失材料说明或备注，除非用户提供的示范本身有这些内容。

常用顺序按用户示范：

```text
1-委托代理协议
2-发票
3-授权委托书及身份材料
4-所函
5-起诉状
6-财产保全申请书及担保材料
7-证据目录
8-证据材料
9-地址确认书
10-民事调解书
11-结案报告
```

页次规则：

- 按最终合并 PDF 中正文材料的连续页码填写。
- 卷宗目录本身不计入正文页次。
- 如果用户已经手工填写或纠正页次，以用户填写为准，不要擅自重算覆盖。
- 如果用户说“把他们替换你的”，把用户填写的目录文件作为正式版。

## 结案报告填写规则

使用 `结案报告.docx` 原模板。

只填写模板中需要填的位置：

1. 开头句中的律师、客户、签订时间、案件名称。
2. `案情简介` 下方空白处。
3. `办理过程` 下方空白处。
4. `办案结果` 下方空白处。
5. `特殊情况说明（如有）` 下方空白处；没有特殊情况就留空。

不要改动标题、栏目名、签字栏、团队负责人栏、日期栏，除非用户明确要求。

不要扩写成长篇正式报告。内容要简短，通常每栏 1 小段即可。

用户示范风格：

```text
案情简介
广州市果果服饰有限公司注销后，刘妍妤、郝月霞、刘婕妤作为债权继受主体，向申坤坤追索货款本金214469.41元及违约金、律师费、保全担保费等费用。

办理过程
承办律师接受委托后，整理主体材料、授权手续、还款协议、对账材料、催款记录及公司注销、股东身份资料，起草并提交起诉状、证据目录、财产保全申请书、送达地址确认书等材料，并跟进立案、保全及调解工作。

办案结果
调解结案，被告按期还款。
```

如用户未要求编号，不要给各段加 `1、2、3、`。

## 归档合并 PDF

按 `归档范例.pdf` 的类型生成：

1. 第 1 页为卷宗目录。
2. 后续按卷宗目录顺序合并材料。
3. 正文材料连续标注页码；卷宗目录页不计入正文页码。
4. 如后来找到法院 `民事调解书`、判决书、裁定书，应替换此前作为结案依据的私人 `和解协议书`，并同步更新卷宗目录页次和结案报告办案结果。
5. 如用户已经手工填写目录和结案报告，合并 PDF 的目录页和结案报告页应以用户填写内容为准。

## 归档材料检查

民事诉讼归档常见材料：

- 卷宗目录
- 委托代理协议
- 发票
- 授权委托书及身份/主体材料
- 所函
- 起诉状/上诉状/申请书
- 财产保全申请及担保材料，如有
- 证据目录
- 证据材料/证据合并 PDF
- 地址确认书，如有
- 判决书/裁定书/调解书/和解协议等结案依据
- 结案报告

缺失法院结案文书时，可以先说明“预归档”；但一旦用户补充法院调解书、判决书或裁定书，应以法院文书作为正式结案依据。

## 输出

归档完成后，返回：

- 归档目录路径。
- 卷宗目录文件路径。
- 结案报告文件路径。
- 合并 PDF 文件路径。
- 简短说明是否采用了用户填写模板、是否有缺失材料。
