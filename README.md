# 诉讼自动化 Skill（Litigation Skills）

一套装进 AI 助手的**中国民商事诉讼全流程办案技能包**：对着 AI 说一句人话，它就按诉讼律师的流程帮你干活——一键整理证据、一键生成全套起诉材料、一键生成签约合同和授权材料、一键备好开庭提纲、一键写好答辩和质证意见。只要案件文件夹里材料充足，就不用再给 AI 写小作文。

> 适用：中国大陆民商事诉讼 ｜ 已在真实案件中反复验证 ｜ 欢迎同行 Fork 改成自己律所的模板和交付标准

## 为什么开源

法律 AI 最缺的不是又一套神秘提示词，而是**经过真实案件验证、可以被同行检查和改进的流程**。律师的办案经验以前只能锁在脑子里，现在把它写成了可以运行、可以修改、可以继续迭代的 Skill。欢迎拿去跑，也欢迎提 Issue 和 PR。

## 包含的技能（11 个 + 2 个实验版）

| 技能 | 干什么 |
|---|---|
| 诉讼接案评估 | 接案前的案件分析与评估 |
| 委托签约建档 | 委托代理协议、授权委托书、所函、法定代表人身份证明书 |
| 签约文书与身份材料整理 | 签约材料生成与身份信息整理（身份证正反面合成一页 PDF） |
| 原告起诉立案 | 起诉状、证据目录、财产保全申请、财产线索清单，一套立案材料 |
| 被告应诉答辩 | 答辩状、质证意见等应诉材料 |
| 证据管理 | 证据梳理、证据目录、证明目的整理 |
| 法律检索 | 法条与类案检索流程 |
| 庭前与庭审准备 | 开庭提纲、庭审预案 |
| 裁判结果评估 | 判决书分析、上诉/再审评估 |
| 执行程序 | 强制执行申请与执行跟进 |
| 结案归档 | 卷宗整理与归档 |
| skill-update-work/（实验） | 下一代统一版：litigation-skills 路由版 + litigation-document-kit 文书套件，欢迎试用反馈 |

## 安装（以 Kimi 为例，其他支持 Skill 的 AI 同理）

1. 克隆本仓库：`git clone https://github.com/juneeche/litigation-skills.git`
2. 打开 AI 助手，把这个文件夹指给它，发一句话：

   > **扫描文件夹里的 skill，固定成该任务的技能**

3. AI 列出技能清单（接案评估 → 签约建档 → 起诉/应诉 → 证据管理 → 庭审准备 → 裁判评估 → 执行 → 归档）即安装成功。以后接新案子，新开会话，把案件文件夹指给它即可。

## 配合文书模板使用（关键）

技能包需要和**你自己的文书模板**配套：

- 生成规则：AI **复制模板 → 只替换当事人、案由、金额、日期等内容 → 格式分毫不动**
- 把仓库里附带的示例模板（`委托签约建档/`、`被告应诉答辩/`）换成你所里的版本，生成物自动带上你的字体、字号、表格和落款
- 生成后 AI 会自动检查：旧客户名字、旧金额、旧法院有没有删干净

## 使用原则（必读）

1. **本仓库不包含、也不要放入任何客户资料或未脱敏案件信息**。仓库内的模板已全部使用占位符脱敏。
2. 所有输出都是**律师工作辅助**，不能替代律师：每份文书必须由办案律师回到证据和现行法律复核后方可使用。
3. 法条与类案引用须人工核验，注意时效性与地域裁判差异。
4. 涉及个人信息处理（如身份证材料整理）请在本地环境进行，遵守《个人信息保护法》与律师执业保密义务。

## 如何贡献

- 提 Issue：流程漏洞、文书问题、法条更新
- 提 PR：改进提示词、补充模板、新增技能（请确认不含任何真实案件信息）
- Fork 改造：换成你所的模板、文书风格和交付标准，这才是正确的打开方式
